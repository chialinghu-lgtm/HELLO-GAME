# 🎒 國小英語課堂分組互動遊戲平台 (Classroom Games Portal)

本專案專為國小英語教學、平板分組互動與智慧黑板設計。支援一鍵部署至 **GitHub Pages 免費網站**，老師可在大螢幕投影遊戲大廳與專屬分組 QR Code，學生只要拿平板掃描即可即刻組隊開戰！

---

## 🚀 老師如何進入網頁？

### 方式 A：本機電腦直接開啟（備課與預覽）
1. 打開此資料夾 `GAME`。
2. 找到 **`index.html`** 檔案，直接用滑鼠**點擊兩下**（以 Chrome 或 Edge 開啟）。
3. 您將立即看到精美的「互動教學遊戲大廳」，可以點選任何遊戲直接試玩或查看投影 QR Code。

---

### 方式 B：在 GitHub 免費發布為網頁（課堂學生掃碼模式）
只需以下 **3 個步驟**，就能獲得永久免費的線上網址：

#### 第一步：在 GitHub 建立儲存庫 (Repository)
1. 前往 [GitHub.com](https://github.com/) 登入您的帳號（若無帳號可免費註冊）。
2. 點擊右上角的 **`+`** ➔ 選擇 **`New repository`**。
3. **Repository name** 輸入英文名稱（例如：`english-games` 或 `class-games`）。
4. 勾選 **`Public`**（公開）。
5. 點擊下方綠色按鈕 **`Create repository`**。

#### 第二步：上傳本資料夾所有檔案
1. 在建立好的專案頁面中，點擊 **`uploading an existing file`**（上傳現有檔案）。
2. 將本資料夾內的所有檔案與資料夾（包括 `index.html`、`games`、`js`、`css` 等）全部拖曳拖入 GitHub 上傳區。
3. 拖入完成後，點擊下方綠色按鈕 **`Commit changes`** 儲存。

#### 第三步：啟用 GitHub Pages 免費發布
1. 在專案頂端選單點擊 **`Settings`**（設定）。
2. 在左側選單中找到並點擊 **`Pages`**。
3. 在 **Branch**（分支）下方：
   - 將 `None` 切換為 **`main`**（或 `master`）。
   - 資料夾保持選擇 **`/(root)`**。
   - 點擊 **`Save`**。
4. 等待約 1~2 分鐘後重新整理頁面，上方就會顯示您的專屬專屬綠色網址：
   > `https://<您的帳號>.github.io/<專案名稱>/`

*(例如：`https://teacher-chen.github.io/english-games/`)*

## 📱 課堂投影與分組教學流程

1. **投影大螢幕**：
   - 上課時，老師在教室電腦打開您的 GitHub Pages 網址（或是點擊本機 `index.html`）。
2. **選擇遊戲並投影 QR Code**：
   - 點選想進行的遊戲卡片上的 **「📱 投影 QR」** 按鈕。
   - 畫面會跳出超大、高清晰度的 QR Code 投影彈窗。
3. **動態分組（第 1~6 組 / 藍紅隊）**：
   - 點選彈窗上方的 **「第 1 組」、「第 2 組」...「藍隊」、「紅隊」**。
   - QR Code 會自動動態切換！
   - 學生拿平板相機掃描後，載入的遊戲畫面左上方會直接標示為 **「🎯 第 1 組」**，各組數據與狀態分明！
4. **遊戲內課堂浮動工具列**：
   - 每款遊戲畫面左上方均有專屬懸浮選單：
     - **🏠 大廳**：一鍵隨時回到大廳更換遊戲。
     - **🎯 組別**：點擊可隨時切換或重新登記組別。
     - **📱 掃碼**：學生若有人平板連線中斷，可直接互掃組員平板加入。
     - **🔊 聲音**：一鍵課堂靜音（避免全班 6 組同時播放音效過於吵雜）。

## 🛠️ 如何自訂題目？

- **遊戲內即時修改**：大部分遊戲（如《打地鼠》、《蛇梯棋》、《拉霸機》、《城堡防衛戰》）頂部都有「⚙️ 設定面板」，老師可直接在輸入框輸入自選單字（以半形逗號隔開）。
- **匯入 CSV 題庫**：《選擇題搶答拔河賽》與《棒球單字接力賽》支援匯入自訂 CSV 試算表（格式請參考範本 CSV）。
- **永久固化題庫**：所有遊戲皆為純 HTML/JS 靜態檔案，無依賴任何外部伺服器，您也可以直接用文字編輯器開啟修改預設單元內容。
